        What Parse adds

        Parse reads a page image and returns clean Markdown, with tables as real rows and columns. Everything on this tab was computed ahead of time from the demo documents, so nothing here calls a model.

        1. Tables as data

        A financial statement comes out as rows and columns you can load into a spreadsheet or a database, not as a block of text. Pick a table, compare it with the page, and download it.

          2. Scanned and low-quality pages

          A scan has no text layer, so the page has to be read from the image. Each example below is a page made to look like a scan, with the same question answered twice by Claude: once from the page image alone, and once from the text Parse extracted from that image. Compare the two answers with the reference answer.

            3. When you do not need it

            Clean, digital pages such as these annual reports already carry good text, and the assistant also reads the page image when it answers. That is why search and the assistant in this demo use the document's own text with Embed and Rerank, and Parse is kept for scans, for pages with weak text, and for getting tables out as data. Test it on your own documents before you decide.
